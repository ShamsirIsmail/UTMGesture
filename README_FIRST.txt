UTM Gesture Quest V2 — Antigravity starter pack

This is an asset and reference-code pack, NOT a runnable project.

1. Extract this archive to your Antigravity project folder.
2. Use reference/Gemini_Original_App.tsx as the old Gemini app source to migrate, not as a pre-built full Vite project.
3. Place backgrounds in public/assets/backgrounds/ and access them via:
   /assets/backgrounds/welcome_bg.webp
   /assets/backgrounds/instruction_bg.webp
   /assets/backgrounds/gameplay_bg.webp
   /assets/backgrounds/complete_bg.webp
4. Ask Antigravity to create/fix the Vite + React + TS project, ensure all dependencies and offline MediaPipe assets are present.
5. Test webcam mode locally on localhost and mouse preview separately.

No official UTM logo is included; use an authorized logo image if available.
